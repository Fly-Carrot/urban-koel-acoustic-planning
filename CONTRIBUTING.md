# Contributing

Please open an issue explaining the proposed change, or submit a small, focused pull request.

- Keep raw audio, exact coordinates, credentials and private input files out of Git.
- Explain changes to models, folds or prediction-support rules and update the relevant method notes.
- Keep weekly opportunity (`psi`), detectability (`p`), positive-day minute probability (`mu_plus`) and sampled-minute exposure (`E`) distinct.
- Run `make smoke`, `make verify` and `make test`; include results and any skipped checks.
