## Privacy note

Table S1 uses anonymised public station codes and omits exact coordinates. Table S16 reports route-specific candidate ranks without exact HEX identifiers or centroids. Table S17 records this public-release scope. These redactions protect equipment and site privacy and do not change the reported aggregate results.
